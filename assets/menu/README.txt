Prepared art and fonts for the in-game Mod Menu. Font and icon pixels use tightly packed RGBA8 bytes. See Assets.generated.h or assets.json for sizes and glyph metrics. Font baseline is top y + ascent; each glyph uses bearingX/bearingY from the baseline. Use linear filtering and clamp edges. A transparent gutter surrounds every glyph. The original Nunito and Lilita One font licenses are included. Native game artwork comes from the game's own assets and cursor archive; small icons are CPU filtered to their display size. This does not install or launch the game.
